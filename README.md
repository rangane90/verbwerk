# Verbwerk — German Verb Trainer

A mobile-first, installable Progressive Web App (PWA) starter for German verb study.

## Included
- 5 A2.2 verbs per lesson for the first four lessons (20 verbs).
- A B1.1 starter set of 5 verbs (lesson 5).
- Infinitive, meaning, six present-tense forms, Präteritum, Perfekt, Partizip II and auxiliary.
- Case/preposition patterns, reflexive/separable notes, German examples with English translations.
- Cumulative review, meaning quizzes, weak-verb tracking, searchable library and progress.
- Speech synthesis pronunciation where supported.
- Local browser storage and JSON export/import backup.
- PWA manifest and service worker for installation/offline shell caching when served over HTTPS.

## iPhone installation
The app must be served from an HTTPS address for reliable PWA installation and offline caching. After hosting the folder as a static site, open its URL in Safari, tap Share, then Add to Home Screen. Once opened online at least once, the app shell can be cached for offline launching.

Opening `index.html` directly from the Files app is useful for a quick preview, but iOS may restrict persistent storage, speech and installation for local file URLs.

## Progress and privacy
No account or backend is used. Progress is stored in browser local storage on this device. Clearing browser/site data can erase progress. Use Export progress backup regularly.

## Learning level
You are currently studying A2.2 and plan to start B1.1 on 3 December 2026. This starter build includes 20 A2.2 verbs and 5 B1.1 verbs; it is a working first version, not a complete daily curriculum through B1.1. Additional curated lessons can be added without changing your progress format.
